## `backtest`

Walk-forward backtest: margin error, win-probability calibration and comparison with an Elo-only baseline and the closing spread.

Sources: CollegeFootballData.com, derived. Rows: —. CSV: no.

- Each season is predicted using only data from before each game; settings are chosen using earlier seasons only. 2019-2020 are warm-up/training only.
- Evaluated on FBS-vs-FBS games with a closing line (median across books listed by CFBD).
- Market win probability = normal CDF of the closing spread / its historical error SD.
- Spreads are used here only to measure accuracy; this site has no wagering features.
- model_adjusted = baseline + fitted adjustments (rest, travel, turnovers, recent form); adjustments for season S are fitted on earlier seasons' out-of-sample residuals.
- Totals: projected combined points vs the actual total and vs the closing total.

Object with keys: `headline`, `beats_market`, `test_seasons`, `overall`, `per_season`, `calibration`, `chosen_params`, `ats_edge_threshold`, `model_adjusted`, `totals`, `adjustment_fits`, `margin_total_resid_corr`, `grids`
